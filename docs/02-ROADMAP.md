# Roadmap

## Phase 0 — Blank responsive magazine prototype

Goal:
Prove that the blank reading experience looks and feels premium.

Build:
- Flipbook shell
- Front/back cover
- Blank pages
- Desktop two-page spread
- Mobile one-page mode
- Controls, page count, basic navigation
- Zoom and full screen
- Blank templates
- Basic interaction demos
- Basic animation demos

Do not build:
- Real content
- Database
- Authentication
- Admin editor
- AI integration
- News automation
- Public website
- Domain
- Payments

## Phase 1 — First real issue

Goal:
Publish one complete sample issue using validated templates.

Build:
- Cover
- Contents
- AI/technology Signals
- Main feature
- Explainer
- Data page
- India/work page
- Quiz/poll
- Back cover
- Source and asset credits

## Phase 2 — Data-driven issue system

Goal:
Build a second issue by editing data rather than rewriting layouts.

Build:
- Issue/page schema
- Template registry
- Local JSON content
- Template variants
- Theme and interaction settings

## Phase 3 — Editorial studio

Goal:
Create issues without editing source code.

Build:
- Admin login
- Issue/page editor
- Media upload/library
- Template selection
- Page ordering
- Hotspots
- Draft/preview/publish workflow

## Phase 4 — Advanced editor

Goal:
Support special art-directed pages.

Build:
- Free-position canvas for selected pages
- Drag, resize, rotate, layer
- Snap-to-grid
- Undo/redo
- Autosave
- Overlap/margin/contrast safety checks

## Phase 5 — AI editorial assistant

Goal:
AI helps create drafts but never publishes automatically.

Build:
- Source summarisation
- Headline and story drafting
- Template/theme/interaction suggestions
- Quiz/poll/chart ideas
- Draft page-data output
- Mandatory human review

## Phase 6 — Research automation

Goal:
Reduce manual research workload.

Build:
- Approved RSS/API source collection
- Duplicate grouping
- AI tags and scoring
- Editorial shortlist
- Human selection and verification
- Draft issue creation

## Phase 7 — Public platform

Goal:
Launch a complete public publication site.

Build:
- Home
- Current issue
- Archive
- Responsive story pages
- Topic pages
- About/editorial/corrections pages
- Subscribe/newsletter
- Search
- SEO and sharing
- Domain/deployment

## Phase 8 — Growth and business

Build only after repeated issues and reader feedback:
- Reader accounts/bookmarks
- Analytics
- Sponsorship workflow
- Membership
- Jobs/community/events
- Partner editions
- Additional categories
